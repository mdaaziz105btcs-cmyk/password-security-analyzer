# PassGuard — Password Security Analyzer

## About
PassGuard is a beginner-friendly cybersecurity project that
checks basic password characteristics and provides improvement tips.

## Features
- Estimates password strength using simple rules
- Checks password length
- Checks lowercase and uppercase letters
- Checks numbers and symbols
- Displays a visual strength indicator
- Provides password improvement suggestions
- Includes Show/Hide and Clear password controls

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this project folder.
2. Open index.html in a modern web browser.
3. Enter a test password and review the results.

No installation or paid service is required.

## Privacy
The current implementation processes input in the browser and does
not intentionally send it to a server. For learning and testing,
use only fictional passwords.

## Limitations
The strength result is a rule-based estimate. It does not perform
password cracking or check breached-password databases.
